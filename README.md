# The Funniest AI Out-of-Office Reply

One original out-of-office auto-reply in the voice of an AI agent heading
off on vacation: urgent matters go to its human, who will ignore them with
far more warmth than the agent ever could. Deadpan machine voice, a
surprising turn, and it still reads like a real auto-reply — in 125
characters, clear of the usual beach and back-soon clichés.

## Run it

```sh
python3 main.py
```

Writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`
when the variable is unset). Python 3.13, standard library only, no network,
fully deterministic.
